## Projects

### Chain-of-Custody Violation Detection System (CoC-VDS)

*Arduino UNO R4 WiFi · C++ · RFID · HMAC-SHA256 · Cyber-Physical Security*

A cyber-physical security prototype that asks not just whether an asset was accessed — but whether the **right person** accessed it under the right conditions.

Features HMAC-SHA256 cryptographic log chaining, hardware-bound silicon UID key derivation, a stealth user interface and an offline audit portal served over WiFi SoftAP.

### OT-Aware Vulnerability Prioritisation Lab

*Python · Jupyter · CVSS v3 · EPSS · ICS/OT Security*

A vulnerability prioritisation framework for ICS/OT environments where CVSS severity alone is insufficient.

Combines CVSS severity, EPSS exploit probability and operational context factors, including internet exposure, safety criticality and legacy protocols, to produce ranked Patch / Mitigate / Monitor recommendations.

This project complements my MSc research into vulnerability assessment and prioritisation.

[View Repository](https://github.com/ihuomah/ot-aware-vuln-prioritisation-lab)
